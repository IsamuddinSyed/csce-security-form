# CSCE Security Form

This is a very small Node.js and Express login-form project. It validates an email and password in the browser and on the server, then displays a success or error message.

It does not use a database and does not perform real authentication.

## Requirements

- Node.js (version 18 or newer recommended)
- npm

## Install dependencies

From this project folder, run:

```bash
npm install
```

## Run the project

```bash
npm start
```

Then open http://localhost:3000 in a browser.

## Local cybersecurity lab

This project was created as a local cybersecurity lab to demonstrate both client-side and server-side input validation. It is for learning purposes only and is not a real login system.
